01 / CI·CD & GITOPS

Commit to cluster.
In about 49 seconds.

A seven-stage Jenkins pipeline that builds, checks, secures and delivers a Java application to Amazon EKS.

  • Jenkins
  • Docker
  • ArgoCD
  • Kubernetes
  • AWS EKS
Explore the engineering +
  • GitHub webhooks trigger the Jenkins Declarative Pipeline on EC2.
  • SonarQube Quality Gates and Trivy stop quality failures and HIGH/CRITICAL vulnerabilities.
  • Maven builds the application into versioned Docker images.
  • ArgoCD syncs updated GitHub image tags to Amazon EKS.
  • Two replicas, health probes and rolling updates maintain availability.
  • Prometheus and Grafana monitor pod health; credentials stay outside source code.

02 / INFRASTRUCTURE AS CODE

Built to scale.
Designed to recover.

A self-healing web tier across two Availability Zones. Terraform provisions the infrastructure; Auto Scaling keeps it running.

  • Terraform
  • EC2
  • VPC
  • Auto Scaling
  • ALB
Explore the architecture +
  • Custom VPC (10.0.0.0/16) separates public and private subnets.
  • Nginx runs in Docker behind an Application Load Balancer.
  • An Auto Scaling Group replaces failed instances automatically.
  • Bash User Data and AWS CLI scripts automate setup and access.
  • IAM roles provide read-only S3 access without stored access keys.
